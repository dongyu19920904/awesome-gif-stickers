## 商店投稿：先核入口，再读实操

### 04 · 微信表情开放平台服务协议

### 05 · 微信表情制作规范与审核标准

[制作规范](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications#specifications_stickers) · [审核标准](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/auditingStandards#auditingStandards_demand) · 微信表情团队 · 官方指南

制作投稿物料前的首要参考，覆盖表情图、专辑横幅、封面、聊天面板图标及内容要求。核查到的公共指南写明：动态主图为 **240×240 GIF、不超过 500KB**；一套专辑可有 **8～24 张**，同套统一为动态或静态。

**版本提示：**上述内容来自官方页面引用的公共资源，`Last-Modified` 为 **2026-07-01**，仍由本次读到的服务协议链接。它是带日期的公开参考，不能称为 11 月最新登录后台已确认标准；正式提交前以实际入口的字段和校验为准。旧教程中的“固定 16/24 张”“所有物料 80KB”“必须另交 120×120 缩略图”不宜直接照搬。

## 原生 GIF 到微信的作者案例

### 10 · 弎弎水：锚点图、两套动态表情与深色背景处理

[阅读作者原帖](https://x.com/vastxie/status/2118265895613346263) · 弎弎水 / vastxie · 2026-11-05 · 原帖全文已通过公共HTTP接口补核

原帖按四步介绍两套、共32张表情的制作：先生成一张GIF并取首帧固定角色，再将锚点图用于其余动作，处理微信深色背景下的白边，最后准备表情图、封面与图标。适合连起来阅读参考图一致性和微信显示效果；具体请求设置和短提示在原文。

作者报告使用赠送 API 额度，约消耗 4 美元。微信上架和收入未获核实。尺寸、透明背景和接口行为来自作者当次调用，投稿时对照 05 的官方入口。

作者后来公开了藏狐参考图的动作模板，以及用 Pillow 保留透明索引色的示例代码。本库已读源码文字，代码运行效果以作者记录为据。 [原词与代码回复](https://x.com/vastxie/status/2118586752915095805)
